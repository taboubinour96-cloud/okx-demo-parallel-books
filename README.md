**مجاناً وبلا حدود زمنية**، بعكس المستودعات الخاصة (محدودة بدقائق شهرية مجانية ثم

- الحساب حساب Demo فقط، لا يمكنه لمس أموال حقيقية.

## التشغيل
`.github/workflows/run-books.yml` يشغّل `bot/run_books.py` تلقائياً كل 4 ساعات،
وأيضاً بزر يدوي فوري من تبويب Actions. كل تشغيل:
1. يقرأ بيانات OKX الحية.
2. يحسب إشارة الاتجاه (book1/book2).
3. يوازن المركز الحقيقي على الديمو حسب الإشارة.
4. يفحص قواعد المخاطر (خسارة يومية، أقصى تراجع) — عند أي خرق: تسطيح فوري + توقف
   حتى تدخل بشري.
5. يحفظ النتيجة في `ledgers/*.json` ويرفعها لنفس المستودع.
